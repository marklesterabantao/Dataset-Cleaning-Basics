# Dataset-Cleaning-Basics
Basic dataset cleaning examples in Python: handling missing values, outliers, and encoding categorical data using pandas.

This repository contains basic examples of dataset cleaning in Python using pandas.  
It focuses on three common and important tasks:

1. **Handling Missing Values**  
   - Detect missing values  
   - Drop rows with missing data  
   - Fill missing values using mean or median  

2. **Handling Outliers**  
   - Visualize outliers using boxplots  
   - Detect outliers using the IQR (Interquartile Range) method  
   - Remove outliers to get a cleaner dataset  

3. **Encoding Categorical Data**  
   - Convert text categories into numbers using label encoding  
   - Use one-hot encoding to create binary columns for each category  

All examples are implemented in a Jupyter Notebook (`dataset_cleaning_basics.ipynb`) with step-by-step comments to help beginners understand the concepts clearly.
